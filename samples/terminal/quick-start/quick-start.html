Quick start

Quick start

Add the dependency and cache your first value in five minutes.

This tutorial takes about five minutes. You will add Acme Cache to a project, build a cache, and watch it evict.

1. Add the dependency#

dependencies {
    implementation 'dev.example:acme-cache:1.2.0'
}
dependencies {
    implementation("dev.example:acme-cache:1.2.0")
}
<dependency>
  <groupId>dev.example</groupId>
  <artifactId>acme-cache</artifactId>
  <version>1.2.0</version>
</dependency>

2. Build a cache#

Everything starts at Cache.builder():

Main.java
import dev.example.cache.Cache;
import dev.example.cache.EvictionPolicy;

public class Main {
    public static void main(String[] args) {
        Cache<String, Integer> lengths = Cache.<String, Integer>builder()
                .maximumSize(2)
                .evictionPolicy(EvictionPolicy.LRU)
                .recordStats()
                .build();

        lengths.put("one", 3);
        lengths.put("two", 3);
        lengths.get("one");          // "one" is now the most recently used
        lengths.put("three", 5);     // evicts "two"

        System.out.println(lengths.get("two").isPresent()); // false
        System.out.println(lengths.stats());
    }
}

3. Load values on demand#

Most caches are filled lazily. Cache.getOrLoad(Object, java.util.function.Function) loads a value once and serves it from memory afterwards:

String page = pages.getOrLoad(url, httpClient::fetch);

Warning

The loader must not return null. A null result raises a CacheLoadException.
