CacheBuilder

public final class CacheBuilder<K, V>

Configures and creates Cache instances.

Every setting is optional. A builder can be reused: each call of build() creates an independent cache. 

Cache<String, byte[]> thumbnails = Cache.<String, byte[]>builder()
        .maximumSize(500)
        .evictionPolicy(EvictionPolicy.LFU)
        .recordStats()
        .build();

Parameters

<K>the type of keys of the cache to build
<V>the type of values of the cache to build
API note

This class is not thread-safe; configure it on one thread, then share the cache.

Since

1.0
