Setup

Configuration

Acme Cache is configured in code, through CacheBuilder. There are no configuration files and no system properties.

Settings at a glance#

Method Default Effect
CacheBuilder.maximumSize(long) unbounded Caps the number of entries
CacheBuilder.expireAfterWrite(java.time.Duration) never Expires entries after a time to live
CacheBuilder.evictionPolicy(EvictionPolicy) EvictionPolicy.LRU Chooses the entry to evict
CacheBuilder.recordStats() off Enables Cache.stats()

Sizing a cache#

Choose the size from the memory you can spare, not from the number of entries you hope to store:

  1. Estimate the average size of one entry.
  2. Multiply by the number of entries you want to keep.
  3. Add 30% for overhead.
  • Set a maximum size
  • Record statistics in production for a week
  • Tune the eviction policy based on the hit rate
