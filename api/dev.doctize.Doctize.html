classdev.doctize

Doctize

public final class Doctize

Generates a documentation site from the Javadoc of annotated types and from Markdown guides.

Doctize.builder()
        .configFile(Path.of("doctize.yml"))
        .model(Path.of("build/classes/java/main"))
        .output(Path.of("build/docs"))
        .build()
        .generate();

Every setting is optional. Left out, Doctize looks for what a project usually has, relative to the base directory: the output of the annotation processor in build/classes/java/main (Gradle) or target/classes (Maven), guides in docs, and the address of the repository in the Git remote origin, if it is on GitHub, GitLab, Bitbucket or Codeberg. So Doctize.builder().build().generate() documents a project without further configuration.

The structure of the site can be declared in the configuration file, or in code with Builder.section(String). Additional pages can be contributed with Builder.pageSource(PageSource).
