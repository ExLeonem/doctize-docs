Declaration

public record Declaration(ElementKind kind, String name, String qualifiedName, String packageName, String signature, List<String> annotations, List<Parameter> parameters, String returnType, List<String> thrownTypes)

The structural facts about a Java element, independent of its documentation comment.

Parameters

kindthe kind of element
namethe simple name
qualifiedNamethe fully qualified name; members are qualified by their owner
packageNamethe package the element lives in
signaturethe declaration as Java source, with simple type names
annotationsthe source form of the annotations present, e.g. @Deprecated
parametersthe parameters of a method or constructor, empty otherwise
returnTypethe return type of a method, null otherwise
thrownTypesthe declared exception types of a method or constructor
