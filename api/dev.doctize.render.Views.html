classdev.doctize.render

Views

public final class Views

The data the theme's templates can use. Templates are logic-less, so these records carry everything ready to print: HTML fields (...Html) are inserted unescaped with {{{triple braces}}}, all other strings with {{double braces}}.

URL fields are relative to the site root; templates prefix them with {{basePath}}.
