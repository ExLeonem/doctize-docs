API Reference
annotationdev.doctize.annotations

Doc

@Documented
@Retention(SOURCE)
@Target({TYPE})
public @interface Doc

Publishes a type as a page of the API reference.

The Javadoc comment of the annotated type, and of its public and protected members, becomes the page content. Comments are written in Markdown (JEP 467 /// comments work best, but classic /** */ comments are supported too) and may use the standard Javadoc tags such as @param, @return, @throws, @since, @see and {@link ...}. Unknown block tags are rendered as labelled blocks. 

/// A cache with a bounded size.
///
/// @since 1.2
@Doc(section = "Caching", order = 10)
public interface Cache<K, V> { ... }

The annotations have source retention: they are read while your code compiles and leave no trace in class files, so libraries that use them impose no dependency on their users.

Methods#

section() method # 

String section() default ""

The section the page is listed in, given either as its id or its title. Sections that are not declared in the site configuration are created on demand. When empty, the configured API section is used ("API Reference" by default).

title() method # 

String title() default ""

The page title. Defaults to the simple name of the type.

order() method # 

int order() default 100

Sorting key: lower values come first, ties are broken by title. Pages that share a group stay together, and groups are ordered by the lowest order among their pages.

group() method # 

String group() default ""

Label used to group pages in the navigation. Defaults to the package name.

keywords() method # 

String[] keywords() default {}

Extra terms that should find this page through search, e.g. synonyms.

members() method # 

boolean members() default true

Whether the public and protected members of the type are documented as well.
