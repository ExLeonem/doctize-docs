Doctize.Builder

public static final class Builder

Collects settings; every setting given here wins over the configuration file.

Methods#

configFile() method # 

public Doctize.Builder configFile(Path file)

Uses a doctize.yml; relative paths inside it are resolved against its directory.

config() method # 

public Doctize.Builder config(DoctizeConfig config)

baseDirectory() method # 

public Doctize.Builder baseDirectory(Path directory)

Where relative paths from the configuration are resolved. Defaults to the working directory.

model() method # 

public Doctize.Builder model(Path location)

Adds the compiled output of a module (or a model file or jar) to document. May be called repeatedly. Without one, build/classes/java/main and target/classes below the base directory are used if they contain a model.

guides() method # 

public Doctize.Builder guides(Path directory)

The directory with Markdown guides. Default: guides of the configuration, or else docs, if it exists.

theme() method # 

public Doctize.Builder theme(Path directory)

A custom theme directory that is layered over the built-in theme.

themeName() method # 

public Doctize.Builder themeName(String name)

A named theme, e.g. ocean, layered under a custom theme directory and over the built-in theme. Replaces theme.name of the configuration file. The themes besides default come from dev.doctize:doctize-themes on the class path; Theme.available() lists them.

output() method # 

public Doctize.Builder output(Path directory)

baseUrl() method # 

public Doctize.Builder baseUrl(String baseUrl)

Tells Doctize where the site will be published, e.g. https://acme.github.io/cache/. With a known address the output also contains a 404.html that works at any depth, sitemap.xml, robots.txt and canonical links. Replaces hosting.baseUrl of the configuration file.

Parameters

baseUrlStringan absolute http(s) URL

githubPages() method # 

public Doctize.Builder githubPages()

Prepares the output for GitHub Pages: adds .nojekyll, so that GitHub publishes the files as they are. Unless baseUrl(String) says otherwise, the address is derived from project.repository.

customDomain() method # 

public Doctize.Builder customDomain(String domain)

The custom domain of a GitHub Pages site, e.g. docs.acme.dev; written to the CNAME file.

section(String) method # 

public Doctize.Builder section(String title)

Declares a section in code. The declaration order is the navigation order; once any section is declared here, the sections of the configuration file are ignored.

section(SectionSpec) method # 

public Doctize.Builder section(SectionSpec section)

projectDefaults() method # 

public Doctize.Builder projectDefaults(ProjectInfo project)

Project data for what the configuration file does not set, typically what the build tool knows: the name, version and description of the project. Unlike the other settings here, the configuration file wins.

pageSource() method # 

public Doctize.Builder pageSource(PageSource source)

Contributes additional pages, e.g. a changelog generated from a file.
