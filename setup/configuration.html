Setup

Configuration

Every setting of doctize.yml.

The configuration file is optional, and so is every setting in it: a project with the usual layout is documented without one, see the defaults below. Unknown keys are rejected, so a typo such as projekt: is reported instead of silently ignored.

doctize.yml
project:
  name: Acme Cache
  tagline: A small, fast, bounded in-memory cache for Java.
  version: 1.2.0
  repository: https://github.com/acme/acme-cache
  footer: © 2026 Acme Corp.

theme:
  name: ocean
  path: my-theme
  accent: "#0d9488"
  extraCss: [brand.css]
  extraJs: [brand.js]
  options:
    banner: "We are hiring"

guides: docs
defaultSection: Guides

sections:
  - id: quick-start
    title: Quick start
    description: Add the dependency and cache your first value.
  - Setup
  - id: api
    title: API Reference

api:
  section: API Reference
  includeUndocumented: true

hosting:
  githubPages: true
  baseUrl: https://acme.github.io/acme-cache/
  customDomain: docs.acme.dev

Relative paths (theme.path, extraCss, extraJs, guides) are resolved against the directory that contains the file. The settings map onto DoctizeConfig.

project#

Shown in the header, on the home page and in the footer. See ProjectInfo.

Key Default Meaning
name the build's project name, else Documentation The name in the top bar, the home page and the browser title.
tagline the build's project description, else empty One line below the name on the home page.
version the build's project version, else empty Shown as a badge next to the name.
repository the Git remote origin, see below Adds a repository icon that links here to the top bar; without a repository there is none.
footer empty A line of text in the footer of every page.
sourceUrl derived from repository, see below The address of a line in a source file, with {path} and {line}. API pages link to it.
hideRepository false Leaves out everything that links to the repository: the repository icon and the links to the source.

The build's project data is what the Gradle plugin passes (the name of the root project, and the version and description of the project), or the --project-... options of doctize generate. Whatever this file sets wins.

Without repository, Doctize reads the remote origin (or else the first remote) of the Git repository the project is in. An address on github.com, gitlab.com, bitbucket.org or codeberg.org is turned into its web address, e.g. git@github.com:acme/cache.git into https://github.com/acme/cache, without any credentials; a remote on another host is not published unless you name it here.

Links to the source#

Every API page, and every member on it, has a code icon (</>) that opens the line of the source file where it is declared. The annotation processor records that line and the path of the file relative to the root of the Git repository. For a repository on github.com, gitlab.com, bitbucket.org or codeberg.org, the address is derived from repository and the branch that is checked out, or the commit when no branch is (as in most CI builds). A branch that the remote does not have yet links to the remote's default branch instead, where lines may have moved until you push. For another host, or to link to a tag, set it:

doctize.yml
project:
  sourceUrl: https://git.acme.com/cache/-/blob/v2.0/{path}#L{line}

Without a known address, or for sources outside a Git repository, the icons are left out.

Hiding the repository#

For a private repository, or one you do not want to advertise, set hideRepository. The site then has neither the repository icon in the top bar nor the links to the source, whether repository and sourceUrl are set or found in the Git remote. The repository is still used where it does not show: with githubPages, the address of the site is derived from it.

doctize.yml
project:
  hideRepository: true

theme#

See ThemeSettings and Theming.

Key Default Meaning
name default A ready-made theme: ocean, forest, paper, contrast, terminal.
path none A directory with a custom theme, layered over the built-in theme and the named one.
accent theme default A CSS colour for links and highlights.
extraCss none Stylesheets added after the theme's own. Copied to assets/custom/.
extraJs none Scripts added at the end of every page. Copied to assets/custom/.
options none Free-form text values your templates can read as {{theme.options.<key>}}.

guides and defaultSection#

Key Default Meaning
guides docs, if it exists The directory with Markdown files, see Structuring the site.
defaultSection Guides The section for Markdown files in the root of that directory that do not name one.

sections#

The list of sections in navigation order, see SectionSpec. An entry is either a plain title or a mapping:

Key Default Meaning
id the slug of title Used in URLs (<id>/page.html) and to refer to the section from pages.
title the id, capitalised The name in the navigation.
description empty The teaser on the home page.

api#

See ApiSettings.

Key Default Meaning
section API Reference The section for @Doc types that do not name one.
includeUndocumented true Whether members without a doc comment are listed.

hosting#

Where and how the site is published; see Publishing to GitHub Pages and HostingSettings.

Key Default Meaning
baseUrl derived, see below The address the site is published at, e.g. https://acme.github.io/acme-cache/. Enables 404.html, sitemap.xml, robots.txt and canonical links.
githubPages false Prepares the output for GitHub Pages: writes .nojekyll (and CNAME for a custom domain).
customDomain none A host name such as docs.acme.dev for a GitHub Pages site.

If baseUrl is not set, the address is https://<customDomain>/, or, with githubPages, derived from project.repository.
